# 🚀 Quick Start - Inicio Rápido

## En Español

### Inicio Rápido (5 minutos)

1. **Clonar el repositorio:**
```bash
git clone https://github.com/Harp09/Wuwa-app.git
cd Wuwa-app
```

2. **Instalar dependencias:**
```bash
npm install
```

3. **Ejecutar en Android:**
```bash
npm run android
```

4. **O ejecutar en iOS (solo macOS):**
```bash
cd ios && pod install && cd ..
npm run ios
```

### ¿Qué incluye esta app?

✅ Lista de personajes de Wuthering Waves
✅ Vista detallada con 5 pestañas (Builds, Armas, Ecos, Secuencias, Fondos)
✅ Agregar personajes manualmente
✅ Almacenamiento local (los datos persisten)
✅ 2 personajes de ejemplo incluidos

### Requisitos Mínimos

- Node.js 18+
- Android Studio (para Android)
- Xcode (para iOS, solo macOS)
